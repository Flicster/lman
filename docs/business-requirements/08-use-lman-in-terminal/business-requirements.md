# BP-08.1. Бизнес-требования: пользование Lman в терминале

## Цель

Обеспечить пользователю возможность выполнить действия Lman из терминала короткими командами.

## Бизнес-результат

Пользователь вызывает Lman командой `lman`. Список команд покрывает просмотр языков, сведения о языке, назначение активной версии, правку глобальных переменных, удаление, те же действия на удалённом сервере, а также контекст приложения.

Перечень ниже собран по процессам BP-01–BP-07: во вводных заданы возможности программы, а не имена команд.

## Требования

- Система должна запускаться в терминале командой `lman`.
- Система должна выполнять действия по командам из списка ниже.
- Команда `lman help` должна показывать этот список команд.
- Команда без аргументов `lman` должна показывать перечень установленных языков, как `lman list`.
- Язык и версия в аргументах — человекочитаемые обозначения из перечней Lman, например `go` и `go1.25`. Пользователь не вводит системный идентификатор.
- Критерий удалённого сервера задаётся один раз на вызов и относится к командам языков.

## Список команд

| Команда | Что делает пользователь | Процесс |
| --- | --- | --- |
| `lman` | Видит перечень установленных языков. | BP-01 |
| `lman list` | То же, что `lman` без аргументов. | BP-01 |
| `lman show <language>` | Видит версии, активную версию, пути, метод установки, даты установки и подсказку среды взаимодействия. | BP-02 |
| `lman manual <language>` | Читает мануал языка. | BP-02 |
| `lman env <language>` | Видит глобальные переменные окружения языка. | BP-02 |
| `lman env set <language> <name> <value>` | Задаёт значение одной глобальной переменной языка. | BP-04 |
| `lman use <language> <version>` | Делает версию активной: она исполняется в терминале. | BP-03 |
| `lman remove <language>` | Удаляет язык. | BP-05 |
| `lman remove <language> <version>` | Удаляет конкретную версию языка. | BP-05 |
| `lman status` | Видит время, основные характеристики системы и установленную версию. | BP-07 |
| `lman theme light` | Задаёт световую тему. | BP-07 |
| `lman help` | Видит список команд. | BP-08 |
| `lman --remote <server> <команда>` | Выполняет команду языков на удалённом сервере. | BP-06 |

Команды, которые принимают `--remote`: `list`, `show`, `manual`, `env`, `env set`, `use`, `remove`. Пример: `lman --remote <server> show go`.

`status`, `theme` и `help` остаются на компьютере пользователя. Время, световая тема и характеристики системы описывают локальное приложение.

## Бизнес-правила

- Одна команда выполняет одно действие. Сведения о языке разделены: сводка (`show`), мануал (`manual`) и глобальные переменные (`env`), чтобы длинный текст не смешивался со списком версий.
- `remove` с одним аргументом удаляет язык. `remove` с языком и версией удаляет только эту версию.
- `env set` меняет глобальные переменные, которые показывает `env`. За один вызов задаётся одна переменная: имя и значение.
- `use` выбирает версию среди установленных версий этого языка.
- `--remote` не меняет состав команды. Меняется только компьютер, к которому относятся сведения и результат.
- Активная версия языка по-прежнему означает версию, которая исполняется в терминале (BP-03). Это не команда Lman.

## Область вне требований

- Установка языка, которого на компьютере ещё нет, отдельной команды не имеет: такого действия нет во вводных.
- Удаление отдельной переменной окружения отдельной команды не имеет.
- Подтверждение удаления, формат записи `<server>`, учётные данные и текст ответов команд не описаны во вводных.
- Смысл удаления, состав путей, состав характеристик системы и чья «установленная версия» показывается в `status` остаются открытыми вопросами каталога процессов. Команды только вызывают уже названные действия.
