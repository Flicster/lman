# BP-02.1. Бизнес-требования: просмотр сведений о языке

## Цель

Обеспечить пользователю возможность посмотреть сведения по выбранному установленному языку программирования.

## Бизнес-результат

По выбранному языку видны установленные версии, активная версия, пути, метод установки, даты установки, подсказка среды взаимодействия, мануал и глобальные переменные окружения.

## Требования

- Система должна показывать сведения по языку, выбранному из перечня BP-01.
- Система должна показывать установленные версии языка.
- Система должна помечать активную версию.
- Система должна показывать пути.
- Система должна показывать метод установки.
- Система должна показывать даты установки.
- Система должна показывать подсказку среды взаимодействия языка.
- Система должна давать прочитать мануал по языку.
- Система должна давать просмотреть глобальные переменные окружения языка.

## Бизнес-правила

- Версия языка обозначается так, как установлена, например go1.25.
- Активная версия — та, которая исполняется в терминале. Назначение активной версии выполняется в BP-03.
- Метод установки — напрямую или через пакетный менеджер. Примеры пакетных менеджеров во вводных: apt, brew.
- Подсказка среды взаимодействия поясняет средства работы с языком. Во вводных примеры: python — uvx; JavaScript — node, npx, npm.
- Глобальные переменные окружения и мануал относятся к выбранному языку.
- Редактирование переменных выполняется в BP-04. Удаление языка или версии выполняется в BP-05.

## Область вне требований

- Какие именно пути показывать, не описано.
- Дата установки относится к версии, к языку или к обоим — во вводных не различено.
- Источник мануала и подсказок не описан. Примеры подсказок не задают полный перечень языков и средств.
- Изменение мануала и подсказок пользователем не описано.
