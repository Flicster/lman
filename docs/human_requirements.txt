Lman сервис

Серивис это десктопное приложение на go + Wails.
При открытии покзывает список установленных на компьютере языков программирования (квадртаные блоки 5 в ряд)
После нажатия на конкретном языке попадает на второй экран, где видно установленные версии список, активная версия помечена, есть пути и то как установленна была
Есть кнопки урпавления: сделать активным, удалить
Есть подсказки на тему среды взаимодействия языков, например python это uvx. Java script это node npx npm
Так же видны даты установки
По каждому языку можно посмотреть глобальные перменные окружения и почитать мануал
Приложение доступно на всех os. Windows, mac, linux
Приложение показывает время, имеет настройку световой темы, показывает основные харакетристика системы и установленную версию
Дизайн современный и локаничный
Приложение умеет подключаться к удаленным серверам и делать ве тоже самое там
Архитектуру можно подглядеть в repositories/my/Mnema/ но там python.
ПРограммой можно пользоваться в терминале (есть список команд)

Опеределения
язык программирования - go, Java, JavaScript, python и тд, без языков разметки
версия - версия языка, например go1.25
активная версия - та которая исполняется в терминале
метод установки - нарпямую или через пакетный менедже (apt, brew)

Сценарии
посмотреть список языков
посмотреть исцерпывающюю инфу по языку - версии, активная версия, пути, как устанволен, мануал
сделать версию активной
отредактировать переменные
удалить язык, удалить конкретную версию
