# Источник требований

## Исходный запрос

> Бизнес-требования к проекту менеджера языков программирования.
>
> 1. CLI-утилита для Linux и macOS.
> 2. Сканирование системы и вывод списка установленных языков программирования.
> 3. Просмотр установок конкретного языка: каталоги, версии и активная версия.
> 4. Удаление, обновление и переключение активности выбранной установки.
> 5. Просмотр расположения конфигураций.
>
> Примеры:
>
> ```text
> lman list
> go java python
>
> lman go
> go1.26.5 /usr/local/go/bin/go
> go1.24 /usr/go
>
> lman go cfg
> /home/user/.config/go/env
> ```

## Решение по scope

Текущий этап ограничен read-only функциями:

- обнаружение установленных языков;
- просмотр версий и путей установок;
- определение активной установки;
- просмотр путей конфигураций.

Удаление, обновление, установка и переключение активности перенесены в `roadmap.md`.
