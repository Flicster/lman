# BP-03. Просмотр установок конкретного языка

## Бизнес-требования

- `BR-INFO-01`: По команде `lman <language>` система должна выводить все обнаруженные установки указанного языка.
- `BR-INFO-02`: Для каждой установки система должна выводить версию и путь.
- `BR-INFO-03`: Система должна явно отмечать активную установку.
- `BR-INFO-04`: Активная установка должна определяться по фактическому системному окружению, а не только по сохраненному состоянию утилиты.
- `BR-INFO-05`: Если язык не поддерживается или не установлен, система должна вернуть понятную диагностику и ненулевой код завершения.

## Предусловия

- Пользователь указал язык.
- Для языка существует поддерживаемая стратегия обнаружения и определения активности.

## Основной сценарий

1. Пользователь выполняет `lman <language>`.
2. Система обнаруживает установки указанного языка.
3. Система определяет активную установку.
4. Система выводит версию, путь и признак активности для каждой установки.
5. Команда завершается с кодом `0`.

## Альтернативные и отказные сценарии

- Если язык неизвестен утилите, система сообщает, что язык не поддерживается.
- Если поддерживаемый язык не установлен, система сообщает, что установки не найдены.
- Если активную установку невозможно определить однозначно, система не должна произвольно назначать одну из установок активной.

## Пример

```text
$ lman go
go1.26.5 /usr/local/go/bin/go active
go1.24.0 /usr/go/bin/go
```

## Открытые вопросы

- Как визуально обозначать активную установку?
- Что считать активной установкой, если команда языка отсутствует в `PATH`?
- Следует ли показывать несколько путей, указывающих на одну физическую установку?
