# BP-02. Просмотр списка языков

## Бизнес-требования

- `BR-LIST-01`: По команде `lman list` система должна выводить список языков, обнаруженных на локальной машине.
- `BR-LIST-02`: Язык должен присутствовать в списке только при наличии хотя бы одной обнаруженной установки.
- `BR-LIST-03`: Каждый язык должен выводиться один раз независимо от количества его установок.
- `BR-LIST-04`: Вывод должен иметь стабильный порядок.
- `BR-LIST-05`: Команда просмотра не должна изменять состояние системы.

## Предусловия

- Утилита может выполнить процесс `BP-01`.

## Основной сценарий

1. Пользователь выполняет `lman list`.
2. Система сканирует установки языков.
3. Система формирует уникальный список языков.
4. Система выводит список в стандартный поток вывода.
5. Команда завершается с кодом `0`.

## Альтернативные и отказные сценарии

- Если языки не найдены, система выводит пустой результат или понятное сообщение и завершает команду без ошибки.
- Если часть источников недоступна, система выводит достоверно обнаруженные языки; политика показа предупреждений должна быть определена отдельно.

## Пример

```text
$ lman list
go
java
python
```
