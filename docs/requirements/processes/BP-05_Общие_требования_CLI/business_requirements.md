# BP-05. Общие требования к CLI

## Нефункциональные требования

### `NFR-01` Поддерживаемые платформы

**Требование:** утилита должна работать в Linux и macOS.

### `NFR-02` Только чтение

**Требование:** все команды текущего этапа должны быть read-only и не изменять файловую систему, конфигурации или окружение пользователя.

### `NFR-03` Управляемые ошибки

**Требование:** ожидаемые ошибки должны приводить к понятному сообщению в `stderr` и документированному ненулевому коду завершения без аварийного завершения процесса.

### `NFR-04` Предсказуемый вывод

**Требование:** результаты должны иметь стабильный порядок и не смешиваться с диагностическими сообщениями.

### `NFR-05` Частичная доступность

**Требование:** ошибка чтения отдельного каталога или установки не должна блокировать вывод остальных достоверно обнаруженных данных.

### `NFR-06` Конфиденциальность

**Требование:** содержимое конфигурационных файлов не должно читаться или отправляться за пределы машины; утилита выводит только их расположение.

### `NFR-07` Работа без сети

**Требование:** получение информации об установленных языках и конфигурациях не должно требовать сетевого доступа.

### `NFR-08` Совместимость с автоматизацией

**Требование:** `stdout` должен содержать результат, `stderr` — диагностику; цвет и интерактивное оформление должны отключаться при выводе не в TTY.

### `NFR-09` Производительность

**Требование:** полное локальное сканирование должно завершаться за приемлемое для интерактивной CLI время; численные SLO определяются после выбора языков и каталогов поиска.
