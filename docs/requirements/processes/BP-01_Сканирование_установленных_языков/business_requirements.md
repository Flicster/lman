# BP-01. Сканирование установленных языков

## Бизнес-требования

- `BR-SCAN-01`: Система должна сканировать локальную машину и обнаруживать установленные языки программирования.
- `BR-SCAN-02`: Для каждого поддерживаемого языка система должна обнаруживать все доступные установки, а не только первую найденную.
- `BR-SCAN-03`: Для каждой установки система должна определять версию и путь к исполняемому файлу или каталогу установки.
- `BR-SCAN-04`: Система должна учитывать переменную `PATH`, стандартные системные каталоги и известные пользовательские каталоги.
- `BR-SCAN-05`: Одна недоступная или некорректная установка не должна препятствовать обработке остальных установок.
- `BR-SCAN-06`: Сканирование не должно изменять файлы, конфигурацию или окружение пользователя.

## Предусловия

- Утилита запущена в Linux или macOS.
- Для языка существует поддерживаемая стратегия обнаружения.

## Основной сценарий

1. Система определяет текущую ОС и доступное окружение.
2. Система выполняет стратегии обнаружения для поддерживаемых языков.
3. Для каждого кандидата система проверяет наличие установки и получает ее версию.
4. Система объединяет дубли, сохраняя сведения о различных путях установки.
5. Система передает результат вызывающему пользовательскому процессу.

## Альтернативные и отказные сценарии

- Если установок не найдено, система возвращает пустой результат без аварийного завершения.
- Если каталог недоступен, система продолжает сканирование и сохраняет диагностическую информацию.
- Если версию определить невозможно, установка не должна ошибочно маркироваться как полностью валидная.

## Открытые вопросы

- Какие языки входят в первую поддерживаемую версию?
- Какие каталоги и менеджеры версий проверяются для каждого языка?
- Нужно ли сохранять результаты сканирования между запусками?
