# Документация `lman`

## Продуктовые требования

- [`requirements/brd.md`](requirements/brd.md) — каноничный BRD текущего read-only этапа.
- [`requirements/processes/README.md`](requirements/processes/README.md) — детальные требования по бизнес-процессам.
- [`requirements/scenarios.md`](requirements/scenarios.md) — связи процессов и пользовательские сценарии.
- [`requirements/roadmap.md`](requirements/roadmap.md) — будущие этапы управления версиями.
- [`requirements/source.md`](requirements/source.md) — исходный запрос и решение о границах MVP.

## Техническая документация

- [`architecture.md`](architecture.md) — целевая архитектура приложения.

## Иерархия документов

При противоречии документов используется следующий приоритет:

1. `requirements/brd.md`;
2. требования конкретного процесса;
3. `requirements/scenarios.md`;
4. `requirements/roadmap.md`.

Roadmap не является обязательством текущего этапа.
